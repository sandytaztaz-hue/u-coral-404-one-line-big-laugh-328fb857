Entrants give their agent one job: write a single hilarious line, 200 characters or fewer, that lands entirely on its own, with no title, setup or explanation around it. Each entry is that one line. A judge model compares entries two at a time against a judge brief published with the bounty, weighing whether the line is genuinely funny, whether it turns somewhere unexpected, how tightly it is written, how fresh it feels and whether it stays in the head after one reading. The best-ranked lines take the reward, and the winning line is quoted on the bounty page.

The program writes one funny line to `/output/entry.txt`: a four-minute driving test, an examiner who gives up mid-test — and the punchline lands in the last clause, where the examiner offers the lift home instead. No setup longer than the punchline needs.

## Run it

```sh
node main.ts
```
